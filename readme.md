# AdventureWorks SQL Sales Analysis

This project analyzes sales performance using SQL queries on the AdventureWorks2022 database.

## Key Analysis

- Total revenue and order volume
- Monthly sales trends
- Top selling products
- Customer revenue ranking
- Sales performance by territory

## Tools

- SQL Server
- AdventureWorks2022
- T-SQL

## Skills Demonstrated

- SQL Joins
- Aggregations
- Window Functions
- Business Data Analysis
